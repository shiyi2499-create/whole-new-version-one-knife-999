# 传输指令（PC 端可直接复制）

## 0) 先校验“训练关键文件”是否完整（推荐）
在项目根目录执行（只扫训练必需文件/目录，不看全仓库总数）：

```bash
python3 - <<'PY'
from pathlib import Path

required = [
    "README.md",
    "requirements.txt",
    "feature_extractor.py",
    "preprocessor.py",
    "train_phase2.py",
    "run_transformer_only.py",
    "data/raw/single_key",
    "data/raw/boost",
]

optional = [
    "data/processed/merged_dataset.npz",   # 若你还没在PC预处理，可暂时不存在
    "results",
]

missing = [p for p in required if not Path(p).exists()]
print("=== REQUIRED CHECK ===")
if missing:
    print("MISSING:")
    for p in missing:
        print("  -", p)
else:
    print("OK: all required files/dirs exist.")

print("\n=== DATA SESSION CHECK ===")
single = sorted(Path("data/raw/single_key").glob("*_sensor.csv")) if Path("data/raw/single_key").exists() else []
boost = sorted(Path("data/raw/boost").glob("*_sensor.csv")) if Path("data/raw/boost").exists() else []
print("single_key sensor sessions:", len(single))
print("boost sensor sessions:", len(boost))

print("\n=== OPTIONAL CHECK ===")
for p in optional:
    print(f"{p}: {'OK' if Path(p).exists() else 'NOT FOUND (optional)'}")
PY
```

如果输出里 `REQUIRED` 全部 `OK`，且 `single_key/boost` 的 session 数看起来正常，就可以直接进入训练流程。

### 0.1 如果出现 `MISSING`（像你现在这样）
这通常只有两种情况：
1) 你不在项目根目录执行；  
2) 项目没复制到 PC 或复制到了别的位置。

先定位项目目录（Linux/WSL）：

```bash
pwd
ls -la
find ~ -maxdepth 6 -type f -name "train_phase2.py" 2>/dev/null
```

如果 `find` 找到了路径，切换过去再重跑第 0 步检查脚本：

```bash
cd /找到的那个目录
```

如果 `find` 完全找不到，重新从 Mac 拉取（推荐 rsync）：

```bash
# 在 PC 端执行（把 <MAC_USER>@<MAC_HOST> 换成你的 Mac SSH 账户）
mkdir -p ~/imu_project && cd ~/imu_project
rsync -avz --progress \
  --exclude '.venv' \
  --exclude '.pycache_local' \
  --exclude 'results' \
  '<MAC_USER>@<MAC_HOST>:/Users/shiyi/备份（mac_vs专用）/' ./
```

拉取完成后再次执行第 0 步检查脚本。

## 2) 跑训练的完整指令

### 2.1（推荐）先清理旧缓存结果
```bash
rm -f results/features.npz results/results_phase2.json results/transformer_probs.npz results/ensemble_probs.npz
```

### 2.2 用最新 FFT 预处理重新生成训练集（single_key + boost）
```bash
python preprocessor.py --rounds single_key boost --session-type single_key --target-rate 190
```

### 2.3 4090 服务器（GPU）训练
```bash
PYTHONUNBUFFERED=1 python -u train_phase2.py --profile server --device cuda | tee results/log_train_phase2_server.txt
PYTHONUNBUFFERED=1 python -u run_transformer_only.py --profile server --device cuda | tee results/log_transformer_only_server.txt
```

### 2.4 无 GPU 时（CPU）训练
```bash
PYTHONUNBUFFERED=1 python -u train_phase2.py --profile mac --device cpu | tee results/log_train_phase2_cpu.txt
PYTHONUNBUFFERED=1 python -u run_transformer_only.py --profile mac --device cpu | tee results/log_transformer_only_cpu.txt
```

### 2.5 训练过程监控
```bash
tail -f results/log_train_phase2_server.txt
watch -n 2 nvidia-smi
```
